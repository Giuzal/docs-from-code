# docs-from-code

Generates draft documentation from source code — and measures whether that draft is true.

Documentation drifts away from the code it describes, and a reader cannot tell which parts
still hold. Generating documentation with an LLM is easy; knowing whether the result is
accurate is not. This project treats the measurement as the hard part.

**Status: in progress.** The specification is written — problem, contract, rendering,
and how truth is measured. No working code yet.

See [SPEC.md](SPEC.md).
